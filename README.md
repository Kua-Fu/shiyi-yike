# 诗意一刻 · Chrome 扩展

把“诗意一刻”带进 Chrome：点击工具栏图标，随机遇见一篇先秦至清代的古典诗词。
扩展不会接管浏览器的新标签页，可与 Momentum 等新标签页扩展同时使用。

## 功能

- 完整内置 4834 篇诗词：先秦 370 篇、汉魏六朝 360 篇、唐诗 1500 首、宋代诗词 1704 首、元明清各 300 篇
- 宋代内容细分为宋词 1200 首与宋诗 504 首，兼顾词体名篇和诗歌传统
- 默认展示 938 篇“已校精选”；用户主动选择“全库广览”后，可查看全部 4834 篇及明确标注的待校内容
- 朝代、作者、主题标签和收藏筛选相互联动，扩展运行时无需联网
- 928 位作者均配有人物小传或有限记载说明；点击作者姓名可查看资料来源并继续赏读其作品
- 在当前校订范围内搜索题目、作者、原文、白话译文与标签，并从结果直接进入诗词
- 全部诗词、译文、标签、筛选与人物小传均可一键切换繁体字；默认简体并在本机保存选择
- 点击“X 篇可赏”查看当前筛选结果，并从列表直接打开指定诗词
- 完整展示全部原文与白话译文；938 篇已人工校订，2834 篇待人工校订，1062 篇 AI 辅助草稿
- 收藏喜欢的篇章，通过顶部“收藏”入口集中浏览，并可继续按作者和标签筛选
- 正文资料信息旁提供“纠错”入口，可携带当前篇目信息新建 GitHub Issue
- 一键复制原文、译文、标签、资料来源与校订状态
- 自动下一首默认关闭，可选择 30 秒、1、2、5、10、20、30 或 60 分钟，并通过进度条和倒计时查看剩余时间
- “今日诗签”每天从 938 篇已校精选中稳定选出一篇，同一天反复打开内容不变
- 本机记录今日已读篇数与连续阅读天数；同一天重复打开同一篇不重复计数，统计不会上传
- 随机阅读会优先避开最近读过的 30 篇，并保留会话历史；可点击“上一篇”或按 `←` 原路返回，切换筛选范围时自动清空
- 支持快捷键：`D` 今日诗签，`←` 上一篇，`空格` / `→` 换一篇，`F` 收藏，`C` 复制
- 针对 800×600、1024×600 等低高度窗口提供紧凑布局，筛选和操作区不会挤占正文
- 点击浏览器工具栏图标或使用 `Alt+Shift+P`（macOS 为 `⌘+Shift+P`）打开“诗意一刻”；已有阅读页时直接聚焦，不重复创建页签

## 安装

1. 打开 Chrome，在地址栏输入 `chrome://extensions`
2. 打开右上角的“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目文件夹
5. 在扩展列表中点击“重新加载”，并确认 Momentum 仍处于启用状态
6. 将“诗意一刻”固定到工具栏，点击图标即可打开诗词阅读页

## 与 Momentum 共存

“诗意一刻”不声明 Chrome 新标签页覆盖，仅在用户主动点击工具栏图标时打开独立的诗词阅读页。
如果此前加载过会接管新标签页的旧版本，请在 `chrome://extensions` 中重新加载本项目；若 Chrome
曾停用 Momentum，再手动启用一次即可。

## 校验

项目内置离线繁简转换库，安装 Node.js 后可直接运行：

```bash
npm test
```

如需从开放语料重新生成全部内容数据：

```bash
npm run build:data
```

也可分别运行 `npm run build:preqin`、`npm run build:dynasties`、
`npm run build:tang-song`、`npm run build:song-ci`、`npm run build:song-poetry-selection`、
`npm run build:authors`、`npm run build:review` 和 `npm run build:search`。

作者小传的联网检索结果已固化在扩展数据中。如需重新检索并生成作者资料：

```bash
npm run refresh:authors
```

准备 Chrome Web Store 发布包和商店图片：

```bash
npm run release:prepare
```

产物会生成在 `dist/`。提交商店前还需人工核对
[内容授权审计](CONTENT_LICENSE_AUDIT.md) 中列出的外部授权事项。

## 项目结构

```text
.
├── manifest.json        # Chrome Manifest V3 配置
├── background.js        # 工具栏入口
├── newtab.html          # 工具栏打开的诗词阅读页
├── app.js               # 诗词筛选、人物简介、随机、收藏与复制
├── reading-insights.js  # 今日诗签与本地阅读统计
├── styles.css           # 卷轴式视觉设计
├── assets/              # 扩展图标
├── data/authors.json    # 本地诗人、词人人物简介
├── data/sources/        # 作者小传与译文的来源及许可信息
├── data/poems/search.json # 本地诗词全文搜索索引
└── data/poems/          # 本地诗词索引与 51 个分卷
```

## 内容来源

本项目由 Codex Sites 中的“诗意一刻”第 4 版迁移而来。诗词译文数据中的开放语料沿用原站标注，其中 `Papersnake/gushiwen` 数据集采用 CC0-1.0。

《诗经》《楚辞》原文、200 首新增宋词正文及部分唐宋作者简介整理自 MIT 许可的
[chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 开放数据库。其余作者小传综合
中文维基百科带版本号的条目、古文资料页中的人物事实与本地收录作品整理；维基百科改编内容逐条保留
CC BY-SA 4.0 署名、版本链接与改动说明。先秦白话译文综合
[yht050511/gushiwen](https://github.com/yht050511/gushiwen) 的 MIT 开放数据与
[Papersnake/gushiwen](https://huggingface.co/datasets/Papersnake/gushiwen) 的 CC0-1.0 数据整理，
少量缺篇依据原典与公开注本补写。新增的 500 首唐诗、500 首宋诗，以及汉魏六朝、元、明、清的
原文与译文取自固定版本的 `yht050511/gushiwen` 开放数据；唐宋补充卷限定为结构清晰的五、七言诗，
并按作者均衡抽样、与原诗库去重。新增的 200 首宋词以唐圭璋编、王仲闻参订、孔凡礼补辑的
中华书局《全宋词》为书目参照，正文逐首与固定版本的 `chinese-poetry`《全宋词》开放语料交叉匹配，
白话译文取自 `yht050511/gushiwen`。另依据中文维基百科《宋诗选注》固定版本明确提及的篇目，
补入本地尚缺的 4 首宋诗；仅将该页作为书目与选目线索，原文另据开放语料或公版诗集核对，
白话译文由本项目重新整理，不复制钱锺书的现代序言、注释、评语或版式。待校与 AI 辅助内容只在用户主动进入“全库广览”后展示。界面与诗词内容的
繁简转换由随扩展本地打包的 [opencc-js](https://github.com/nk2028/opencc-js) 完成，运行时不访问
外部服务。详细署名与许可见
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。来源声明与上游权利边界的工程审计见
[CONTENT_LICENSE_AUDIT.md](CONTENT_LICENSE_AUDIT.md)；该审计不替代权利人书面许可或专业法律意见。
