# 诗意一刻 · Chrome 扩展

把“诗意一刻”带进 Chrome：点击工具栏图标，从一篇诗的原文出发，逐句读译注，再理解篇章转折与写法。
扩展不会接管浏览器的新标签页，可与 Momentum 等新标签页扩展同时使用。

官网首页负责说明价值、在线体验与 Chrome 安装转化；在线阅读器仍与扩展共用页面、样式、脚本及诗词数据，
不会维护两套阅读界面。

## 功能

- 默认进入 100 篇深度精读：80 首唐诗、20 首宋词，均已完成人工校订、逐句对齐和原创精读整理
- 第一次打开会先呈现稳定的今日诗签，并用“点一句—看导览—做回想”三步渐进引导建立完整学习路径；完成或跳过后不再打扰
- 轻点任一句原文，就地展开对应白话译文与 2–4 条重点难词，不让整段译文先于原文占据注意力
- 每篇精读固定提供“写作与篇章背景、这首诗写了什么、转折在哪里、它如何写成、核对依据”
- 每篇精读都可进入“不看原文”的逐句补全：先主动回想，再核对完整诗句，避免把“看懂了”误当成“记住了”
- 回想结束后按“还不熟 / 有点模糊 / 已经记住”反馈；低正确率会自动降级，只有完成三次按期复习且全对才会标记为“已掌握”，提前重复练习不能刷进度
- 学习记录与下次复习日期只保存在本机；系统按 1、2、3、7、14 天等间隔安排复习，不收集账号或云端同步
- 顶部“今日”入口会优先显示到期复习及数量；没有到期任务时，每天从 100 篇深度精读中稳定选出一篇
- 另完整内置 5334 篇诗词：先秦 370 篇、汉魏六朝 360 篇、唐诗 2000 首、宋代诗词 1704 首、元明清各 300 篇
- 宋代内容细分为宋词 1200 首与宋诗 504 首，兼顾词体名篇和诗歌传统
- 次级“诗库”抽屉可切换到 938 篇“已校精选”或 5334 篇“全库广览”；待校内容始终明确标注
- 朝代、作者、主题标签和收藏筛选相互联动，完整筛选默认收起，扩展运行时无需联网
- 928 位作者均配有人物小传或有限记载说明；点击作者姓名可查看资料来源并继续赏读其作品
- 在当前校订范围内搜索题目、作者、原文、白话译文与标签，并从结果直接进入诗词；默认精读搜索复用首屏数据，精选与全库按需加载分层索引
- 全部诗词、译文、标签、筛选与人物小传均可一键切换繁体字；默认简体并在本机保存选择
- 点击“X 篇可赏”查看当前筛选结果，并从列表直接打开指定诗词
- 非精读层仍完整展示原文与白话译文；938 篇已人工校订，3334 篇待人工校订，1062 篇 AI 辅助草稿
- 收藏喜欢的篇章，通过顶部“收藏”入口集中浏览，并可继续按作者和标签筛选
- 可进入“专注”模式，只保留题目、朝代作者与诗词原文；自动换诗会暂停，按 `Esc` 或右上角按钮退出
- 正文资料信息旁提供“纠错”入口，可携带当前篇目信息新建 GitHub Issue
- 一键复制原文、译文、标签、资料来源与校订状态；精读作品同时复制难词和篇章导览
- 一键生成 1080×1440 诗词分享图，自动继承当前皮肤与字体并附带离线二维码，可复制图片、调用系统分享或下载高清 PNG
- 自动下一首移入“外观—阅读节奏”并默认关闭，可选择 30 秒、1、2、5、10、20、30 或 60 分钟
- 本机记录今日已读篇数与连续阅读天数；同一天重复打开同一篇不重复计数，统计不会上传
- 随机阅读会优先避开最近读过的 30 篇，并保留会话历史；可点击“上一篇”或按 `←` 原路返回，切换筛选范围时自动清空
- 支持快捷键：`D` 今日诗签，`S` 搜索，`P` 专注，`T` 外观，`←` 上一篇，`空格` / `→` 换一篇，`F` 收藏，`C` 复制
- 针对 800×600、1024×600 等低高度窗口提供紧凑布局，筛选和操作区不会挤占正文
- 点击浏览器工具栏图标或使用 `Alt+Shift+P`（macOS 为 `⌘+Shift+P`）打开“诗意一刻”；已有阅读页时直接聚焦，不重复创建页签

## 安装

1. 打开 Chrome，在地址栏输入 `chrome://extensions`
2. 打开右上角的“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目文件夹
5. 在扩展列表中点击“重新加载”，并确认 Momentum 仍处于启用状态
6. 将“诗意一刻”固定到工具栏，点击图标即可打开诗词阅读页

## 与 Momentum 共存

“诗意一刻”不声明 Chrome 新标签页覆盖，仅在用户主动点击工具栏图标时打开独立的诗词阅读页。
如果此前加载过会接管新标签页的旧版本，请在 `chrome://extensions` 中重新加载本项目；若 Chrome
曾停用 Momentum，再手动启用一次即可。

## 网页版与自定义域名

推送 `main` 分支后，GitHub Pages 会自动发布到
`https://kua-fu.github.io/shiyi-yike/`。域名根路径的 `index.html` 是带搜索摘要、社交分享信息、
在线体验与 Chrome 商店入口的产品官网；`newtab.html` 是与扩展完全共用的在线阅读器。

绑定自己的域名：

1. 打开仓库的 `Settings → Pages`，先确认默认 Pages 地址可以访问
2. 在 `Custom domain` 中填写自己的域名并保存
3. 在域名服务商处配置 DNS：子域名使用 `CNAME` 指向 `kua-fu.github.io`；根域名按
   [GitHub 官方说明](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)
   配置 `A`、`ALIAS` 或 `ANAME` 记录
4. DNS 生效并签发证书后启用 `Enforce HTTPS`

当前仓库从分支发布，GitHub 在保存自定义域名时会创建或更新根目录的 `CNAME` 文件；
后续应保留该文件。不要使用通配符 DNS 记录，以免留下域名接管风险。

## 校验

项目内置离线繁简转换库，安装 Node.js 后可直接运行：

```bash
npm test
```

本地生成与线上相同的网页产物：

```bash
npm run build:web
```

产物位于 `dist/site/`，可用任意静态文件服务器预览。

如需从开放语料重新生成全部内容数据：

```bash
npm run build:data
```

也可分别运行 `npm run build:preqin`、`npm run build:dynasties`、
`npm run build:tang-song`、`npm run build:song-ci`、`npm run build:song-poetry-selection`、
`npm run build:authors`、`npm run build:review` 和 `npm run build:search`。

作者小传的联网检索结果已固化在扩展数据中。如需重新检索并生成作者资料：

```bash
npm run refresh:authors
```

准备 Chrome Web Store 发布包和商店图片：

```bash
npm run release:prepare
```

产物会生成在 `dist/`；商店名称、详细说明、五张截图顺序与权限文案集中维护在
[STORE_LISTING.md](STORE_LISTING.md)。提交商店前还需人工核对
[内容授权审计](CONTENT_LICENSE_AUDIT.md) 中列出的外部授权事项。

## 项目结构

```text
.
├── manifest.json        # Chrome Manifest V3 配置
├── background.js        # 工具栏入口
├── index.html           # 官网获客首页
├── landing.css          # 官网与隐私页样式
├── privacy.html         # 面向用户的网页版隐私说明
├── newtab.html          # 工具栏打开的诗词阅读页
├── app.js               # 逐句点注、回想练习、精读导览、诗库筛选、收藏与分享
├── share-poster.js      # 高清诗词海报、二维码内容与 PNG 文件名生成
├── reading-insights.js  # 今日诗签与本地阅读统计
├── learning-progress.js # 回想判定、掌握门槛与间隔复习排期
├── styles.css           # 卷轴式视觉设计
├── STORE_LISTING.md     # Chrome 商店上架文案与截图顺序
├── assets/              # 扩展图标
├── data/authors.json    # 本地诗人、词人人物简介
├── data/deep-readings.json # 100 篇原创精读稿、难词点注与核对依据
├── data/sources/        # 作者小传与译文的来源及许可信息
├── data/poems/startup.json # 首屏直出的 100 篇完整精读诗词
├── data/poems/search-reviewed.json # 938 篇已校精选轻量搜索索引
├── data/poems/search.json # 本地诗词全文搜索索引
└── data/poems/          # 本地诗词索引与 56 个分卷
```

网页和扩展启动时先读取轻量首屏包，显示第一篇诗词后再补齐完整诗库索引；人物小传、全文搜索、
繁简转换和分享二维码均在实际使用时按需加载，避免移动网络首次访问被非首屏资源阻塞。

## 内容来源

本项目由 Codex Sites 中的“诗意一刻”第 4 版迁移而来。诗词译文数据中的开放语料沿用原站标注，其中 `Papersnake/gushiwen` 数据集采用 CC0-1.0。

《诗经》《楚辞》原文、200 首新增宋词正文及部分唐宋作者简介整理自 MIT 许可的
[chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 开放数据库。其余作者小传综合
中文维基百科带版本号的条目、古文资料页中的人物事实与本地收录作品整理；维基百科改编内容逐条保留
CC BY-SA 4.0 署名、版本链接与改动说明。先秦白话译文综合
[yht050511/gushiwen](https://github.com/yht050511/gushiwen) 的 MIT 开放数据与
[Papersnake/gushiwen](https://huggingface.co/datasets/Papersnake/gushiwen) 的 CC0-1.0 数据整理，
少量缺篇依据原典与公开注本补写。新增的 1000 首唐诗、500 首宋诗，以及汉魏六朝、元、明、清的
原文与译文取自固定版本的 `yht050511/gushiwen` 开放数据；唐宋补充卷限定为结构清晰的五、七言诗，
先按作者均衡抽样，再重点扩展李白、杜甫、白居易等名家诗集，并与原诗库去重。新增的 200 首宋词以唐圭璋编、王仲闻参订、孔凡礼补辑的
中华书局《全宋词》为书目参照，正文逐首与固定版本的 `chinese-poetry`《全宋词》开放语料交叉匹配，
白话译文取自 `yht050511/gushiwen`。另依据中文维基百科《宋诗选注》固定版本明确提及的篇目，
补入本地尚缺的 4 首宋诗；仅将该页作为书目与选目线索，原文另据开放语料或公版诗集核对，
白话译文由本项目重新整理，不复制钱锺书的现代序言、注释、评语或版式。100 篇精读的背景、难词释义与章法导览，
也由本项目在核对既有原文、译文及通行古籍选本后重新撰写，不复制现代赏析文章；具体编辑原则与逐篇依据保存在
`data/deep-readings.json`。待校与 AI 辅助内容只在用户主动进入“全库广览”后展示。界面与诗词内容的
繁简转换由随扩展本地打包的 [opencc-js](https://github.com/nk2028/opencc-js) 完成，运行时不访问
外部服务。详细署名与许可见
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。来源声明与上游权利边界的工程审计见
[CONTENT_LICENSE_AUDIT.md](CONTENT_LICENSE_AUDIT.md)；该审计不替代权利人书面许可或专业法律意见。
