# 诗意一刻隐私政策

更新日期：2026 年 7 月 29 日

“诗意一刻”是一款在 Chrome 新标签页中提供唐诗、宋词浏览、筛选、收藏与复制功能的扩展程序。

## 数据处理

“诗意一刻”不会收集姓名、电子邮件地址、位置、身份验证信息、财务信息、浏览记录、网页内容或其他个人身份信息。

当用户使用收藏功能时，扩展程序仅会将已收藏诗词的内部标识保存在用户设备上的 `chrome.storage.local` 中，用于显示和管理收藏列表。该数据：

- 不会发送至开发者或任何外部服务器；
- 不会出售、共享或转移给第三方；
- 不会用于广告、用户画像、分析、信用评估或贷款；
- 不会用于与扩展程序单一用途无关的目的。

用户可以通过取消收藏、清除扩展程序数据或卸载扩展程序删除这些本地数据。

## 权限说明

扩展程序仅使用 Chrome 的 `storage` 权限，以便在用户设备本地保存收藏状态。扩展程序不会读取用户访问的网站，也不会执行远程托管的代码。

## Chrome Web Store 有限使用要求

“诗意一刻”对用户数据的使用符合 Chrome Web Store 用户数据政策及有限使用要求。扩展程序仅在提供用户可见的收藏功能所必需的范围内处理本地数据。

## 隐私政策变更

如果本政策发生变更，最新版本会发布在本页面，并更新页面顶部的日期。

## 联系方式

如对本隐私政策有任何疑问，请通过项目的 GitHub Issues 页面联系我们：

https://github.com/Kua-Fu/shiyi-yike/issues

# Privacy Policy for Shiyi Yike

Last updated: July 29, 2026

Shiyi Yike is a Chrome extension that provides browsing, filtering, favoriting, and copying of Tang and Song poetry on the Chrome new tab page.

## Data Handling

Shiyi Yike does not collect names, email addresses, location information, authentication information, financial information, browsing history, website content, or other personally identifiable information.

When a user uses the favorites feature, the extension stores only the internal identifiers of favorited poems in `chrome.storage.local` on the user's device. This information is used solely to display and manage the user's favorites. It:

- is not transmitted to the developer or any external server;
- is not sold, shared, or transferred to third parties;
- is not used for advertising, profiling, analytics, credit assessment, or lending;
- is not used for any purpose unrelated to the extension's single purpose.

Users can remove this local data by unfavoriting poems, clearing the extension's data, or uninstalling the extension.

## Permission

The extension uses only Chrome's `storage` permission to preserve favorite status locally on the user's device. It does not read websites visited by the user and does not execute remotely hosted code.

## Chrome Web Store Limited Use

Shiyi Yike's use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. The extension handles local data only as necessary to provide the user-facing favorites feature.

## Changes to This Policy

If this policy changes, the latest version will be published on this page and the date at the top will be updated.
