# 猫猫守卫

原创插画猫咪陪你专注，工作计时结束后在桌面上提醒休息。所有设置保存在本机，不需要登录和联网。

## 使用

Mac 打包产物为 `release/CatGuard-darwin-arm64/CatGuard.app`，双击打开即可，也可以复制到“应用程序”。

1. 设置专注和休息分钟数，点击“开始专注”。
2. 工作时间结束，猫猫在桌面上出现。默认覆盖所有显示器的工作区域，保留系统菜单栏和 Dock / 任务栏，可在设置中改为仅主屏。
3. 休息自然结束后等待下一轮；也可以开启“休息后自动开始下一轮”。
4. 长按按钮 3 秒、点击“结束休息”、按 Esc 或使用菜单栏菜单，都可以解除休息。

“预览猫猫”持续 12 秒，不改变工作计时。关闭主窗口后应用继续在菜单栏运行，退出应用请使用窗口底部或菜单栏的“退出”。另有全局快捷键 `⌘⇧X`（Windows：`Ctrl+Shift+X`）用于结束遮罩。

## 行为说明

- 正在进行的阶段保持原时长，修改时长在下一阶段生效。
- 电脑睡眠时暂停工作计时，唤醒后继续；手动暂停不会被自动恢复。
- 休息以截止时刻计时，睡眠也算休息，醒来后结束已过期的休息。
- “本次”统计仅针对当前运行会话，退出后清零；设置会保留。
- 不自动开机启动，不读取浏览内容、不监控按键、不上传数据。
- 这是可随时解除的休息提醒，不是锁屏或强制访问控制。系统快捷键仍可使用。
- 猫咪为本项目原创 SVG / CSS 动画，未使用参考产品的视频、图标或源码。

## 开发与验证

需要 Node.js 22.12+（打包工具的要求）及 npm。

```sh
npm install
npm start
npm test
npm run test:desktop
npm run package:mac
```

桌面自动化验证会短暂显示主窗口和休息窗口，使用独立临时设置，不覆盖用户设置。截图输出到 `artifacts/`。

`npm run package:win` 可生成 Windows x64 应用目录；Windows 尚需在真实 Windows 环境验证。Mac 当前打包目标为 Apple silicon；Intel Mac 可把打包命令的 `--arch=arm64` 改成 `--arch=x64`。

Mac 本地产物未做开发者签名和公证；面向其他电脑分发前需要完成签名、公证和安装包制作。

## 结构

- `src/timer.cjs`：可用虚拟时钟验证的计时状态机。
- `src/main.cjs`：桌面窗口、菜单栏、多屏、睡眠和权限边界。
- `src/settings.cjs`：本地设置读写与损坏恢复。
- `src/preload.cjs`：窄接口通信桥，页面不能直接访问 Node 或文件系统。
- `ui/`：中文界面、原创角色及呼吸、眨眼、摆尾、抚摸与入场动画。
- `tests/`：计时与持久化测试、真实 Electron 桌面测试。
- `scripts/build-icons.py`：无第三方依赖的原创图标生成器。

本目录是独立应用，有独立依赖和构建命令，不改变上级“诗意一刻”的构建流程。
