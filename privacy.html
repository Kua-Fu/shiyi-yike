隐私说明

你的阅读，只属于你。

诗意一刻不需要账号，不收集姓名、邮箱、位置、浏览记录或网页内容。产品所需的少量学习数据只保存在你的设备上。

更新日期：2026 年 8 月 4 日

只在本机保存什么

  • 收藏的诗词、皮肤、字体、简繁显示与阅读范围偏好；
  • 最近 90 天的阅读篇数、连续阅读天数与当天已读作品；
  • 主动回想的正确率、自评结果、复习间隔与到期日期；
  • 一次性的首访引导完成状态，避免重复打扰。

我们不会做什么

  • 不会把上述数据发送给开发者或任何第三方；
  • 不会出售数据、投放广告、建立画像或跨网站跟踪；
  • 不会读取你访问的网站，也不会执行远程托管代码；
  • 不会在你未主动点击时向 GitHub 或其他外部服务发送内容。

权限与删除

扩展仅申请 Chrome 的 storage 权限，用于在本地恢复偏好、收藏与学习进度，并在当前浏览器会话中复用已打开的阅读页。你可以通过清除扩展数据或卸载扩展删除全部本地记录。

知识纠错

只有当你主动点击“纠错”时，浏览器才会打开 GitHub 新建 Issue 页面，并预填作品标题、作者、内部标识和资料来源。提交前可以检查、修改或删除所有内容；GitHub Issue 通常是公开的，请勿填写个人敏感信息。

完整政策与联系

中英文完整政策与更细的数据字段说明保存在项目的 PRIVACY.md。如有疑问，可通过 GitHub Issues 联系。
